# 0003. Порог релевантности 0.81

Дата: 2026-11-09. Статус: принято (пересмотрено при переходе на e5-base).

## Как калибровали

Пять выданных документов разрезаны тем же кодом, что при загрузке, и закодированы моделью
`intfloat/multilingual-e5-base` (768) с префиксами `query: ` / `passage: `. Для запросов двух видов
сняли косинусную близость трёх лучших фрагментов. Воспроизвести: `uv run python -m evals.calibrate`.

| Запрос | Вид | Лучший | 2-й | 3-й |
| --- | --- | --- | --- | --- |
| Какая мощность у блендера | верный | 0.853 | 0.846 | 0.843 |
| мотор 800 Вт | верный | 0.867 | 0.832 | 0.822 |
| гарантия на блендер | верный | 0.839 | 0.833 | 0.821 |
| объём чайника | верный | 0.816 | 0.801 | 0.797 |
| цена BLD-800 | верный | 0.876 | 0.872 | 0.832 |
| KTL-1700 | артикул | 0.859 | 0.839 | 0.829 |
| рецепт борща | мусор | 0.789 | 0.787 | 0.786 |
| курс доллара на завтра | мусор | 0.789 | 0.787 | 0.787 |
| ремонт автомобиля | мусор | 0.806 | 0.796 | 0.794 |

## Решение

`RELEVANCE_THRESHOLD=0.81`. У e5 близости сжаты в узкую полосу (0.78–0.88), поэтому «типичные» пороги
0.5–0.7 пропускают всё подряд. Верхний результат верных запросов не ниже 0.816, верхний результат
мусорных — не выше 0.806. 0.81 лежит между ними: мусорные запросы не дают ни одного фрагмента,
верные теряют только хвост.

## История

Сначала стояла `intfloat/multilingual-e5-small` (384) и порог 0.82 (верные не ниже 0.841, мусор не выше
0.817). Модель сменили на e5-base (миграция 0009): задание говорит о модели на несколько сотен миллионов
параметров, small для этого мала. Порог откалиброван заново, старые векторы обнулены и пересчитываются
`make reindex`.

## Оговорки

- Набор маленький (пять документов), запас между классами — около 0.01, самый слабый верный запрос —
  «объём чайника». На большом наборе (`data/bulk/`) порог надо перепроверить.
- Порог относится к векторной части. В гибридном поиске фрагмент, найденный по словам (артикул),
  проходит и при низкой близости: иначе гибрид терял бы как раз то, ради чего он нужен.
- Каждая строка спецификации xlsx — отдельный фрагмент «артикул: параметр значение», поэтому артикул
  «KTL-1700» находится и по смыслу (0.859), и по словам.
