# 0002. Стек и границы приложения

Дата: 2026-11-09. Статус: принято.

## Решение

- Python 3.12, FastAPI, Pydantic v2, зависимости через uv (`uv.lock`).
- PostgreSQL 17 с pgvector (образ `pgvector/pgvector:pg17`), драйвер psycopg 3 и `psycopg_pool`.
  Пул создаётся на старте приложения и воркера (`app/core/db.py`: `pool()`, `connection()`),
  соединение берётся на одну операцию, а не на шаг процесса.
- Temporal в dev-режиме одним контейнером; Python SDK `temporalio`. Шаги с базой и диском — синхронные
  активности в пуле потоков воркера.
- Модель — любой OpenAI-совместимый сервер (LM Studio, Ollama, OpenRouter). Клиент — пакет `openai`
  за границей `app/llm/client.py`. OpenAI Agents SDK не подключён: три роли — это три вызова с
  разными промптами, и агентный цикл с инструментами им не нужен; таймаут, повторы и учёт стоимости
  всё равно живут в нашем клиенте.
- Эмбеддинги локально: sentence-transformers, `intfloat/multilingual-e5-base` (768; до миграции 0009 была e5-small, 384), torch из CPU-индекса.

## Слои

- SQL — только `app/repositories/*`.
- Модель — только через `LLMClient.chat`. Он же пишет `llm_calls`.
- Обработчики `app/routers/*` без бизнес-правил: проверка входа, вызов сервиса, ответ.
- Промпты — `app/agents/prompts.py` (детектор инъекций держит свой промпт в `app/guardrails/injection.py`).

## Уровни повтора

- Вызов модели повторяет клиент: только таймаут, сеть, 429 и 5xx; задержка растёт вдвое плюс случайная
  примесь; SDK сам не повторяет (`max_retries=0`). Ошибка в запросе (4xx) не повторяется.
- Шаг процесса повторяет Temporal (`RetryPolicy`, 3 попытки). Невалидный ответ модели, отказ документа
  и ошибка запроса помечены как неповторяемые: повтор шага их не лечит.
